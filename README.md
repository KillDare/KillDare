Desenvolvedor Front-end focado em JavaScript, React e criação de interfaces modernas, acessíveis e performáticas.  
Experiência profissional com desenvolvimento de software, integrações com APIs e sistemas orientados a dados.

## 👨‍💻 Sobre mim

Sou desenvolvedor de software com experiência no desenvolvimento de aplicações multiplataforma utilizando **Delphi**, atuando em projetos que envolvem **integrações com APIs**, comunicação com sistemas bancários e **bancos de dados relacionais**.

Atualmente, direciono meus estudos e projetos para o **desenvolvimento front-end**, com foco em **HTML, CSS, JavaScript e React**, buscando criar interfaces bem estruturadas, responsivas e alinhadas às boas práticas do ecossistema web.

Também estou aprofundando meus conhecimentos em **React Native**, com o objetivo de desenvolver aplicações mobile performáticas e escaláveis.

Sou graduado em **Engenharia da Computação** e estou em constante evolução técnica.
